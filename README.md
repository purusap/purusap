## 🌱 Currently Building

### 🇳🇵 Mero Miti

I'm building **[Mero Miti](https://meromiti.com/)** — a simple way to navigate Nepali dates.

The idea is straightforward:

> **Make Nepali dates as easy to understand and use as Gregorian dates.**

The project focuses on useful everyday tools around the **Bikram Sambat (BS) calendar**, including Nepali ↔ English date conversion and date information.
